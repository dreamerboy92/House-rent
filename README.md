🏠 Room Rent & Expense Splitter
This simple Python program helps divide monthly living expenses like rent, food, and electricity among roommates or flatmates. It takes inputs from the user and calculates how much each person should contribute equally.

📌 Features
Calculates the total electricity bill from units consumed and cost per unit.

Adds up rent, food, and electricity to get the total expense.

Divides the total expense evenly among the number of people sharing the room or flat.

Simple command-line interface for input/output.

📥 Inputs Required
The user will be asked to enter the following:

Total rent of the room/flat

Total food/snacks cost ordered

Total electricity units consumed

Cost per unit of electricity

Number of people sharing the room/flat

🧮 Output
The output will be:
"Each person will pay = X"
where X is the total amount each person owes.

🧰 Technologies Used
Python 3.x

Basic math and input/output functions
